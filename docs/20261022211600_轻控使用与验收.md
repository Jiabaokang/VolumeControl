# 轻控：使用说明与首版验收

## 已实现的范围

轻控用于替代损坏的实体音量键。首版控制媒体音量，覆盖音乐、视频和游戏，不主动调整铃声、通知、闹钟或勿扰模式。

- APP 内显示媒体音量百分比和真实档位，大号加减按钮每次调整一档，滑块可直接选择档位。
- APP 在前台时同步系统或耳机等外部来源的音量变化。
- APP 内提供手电筒开关，采用 Material Design 标准手电筒图形，通过 CameraManager 回调显示真实状态。
- 首次使用手电筒申请相机权限；拒绝权限时提供说明，永久拒绝时提供应用设置入口。不会拍照或录音。
- 提供一个「媒体音量」快捷设置磁贴。Android 公开磁贴接口不支持在磁贴中嵌入自定义 SeekBar，因此点击磁贴后收起下拉面板，并打开轻量悬浮窗口供左右拖动调节。
- 只保留一个「媒体音量」磁贴，点击后打开悬浮滑条。旧版「音量＋」「音量－」磁贴已从清单和代码中删除，不再注册。
- 到达音量上下限后不再越界。固定音量设备显示不可调整状态。
- 支持系统浅色、深色模式和可滚动布局，按钮触控尺寸至少 48 dp。
- 应用中文名为「轻控」，已替换桌面自适应图标，并提供单色图标资源。

## 在手机上使用

打开「轻控」，点击音量按钮或拖动滑块即可调整媒体音量。手电筒开关位于音量卡片下方，开启时卡片显示暖色并标注「已开启」。

当前连接的一加 7 Pro（GM1910，Android 12 / API 31）已安装最新 Debug APK，并将新的「媒体音量」磁贴放在下拉面板前排，原来的两个磁贴已移除。长按磁贴可回到轻控。

在 Android 11/12 手机上，先打开一次应用，再下拉两次展开快捷面板，点击编辑/铅笔按钮，将「媒体音量」拖入常用区域。APP 内也提供了这份引导。

Android 13 及以上版本在 APP 内提供添加「媒体音量」磁贴按钮，调用系统确认弹窗。这条分支已编译检查，尚未在 Android 13 以上真机验证。

手电筒使用系统闪光灯接口；相机被占用时会显示不可用状态。系统结束应用进程时，闪光灯可能随之关闭。首版没有常驻前台服务。

## 构建与安装

项目保留现有 Kotlin / Compose / Material 3 技术栈和依赖版本，没有新增产品依赖。最低 Android 版本为 10（API 29）。当前工程的 Gradle daemon 配置要求 Java 25，可使用本机 Android Studio 自带 JBR：

```sh
env JAVA_HOME='/Applications/Android Studio.app/Contents/jbr/Contents/Home' ./gradlew assembleDebug lintDebug
adb install -r 'app/build/outputs/apk/debug/轻控_v1.0_debug.apk'
adb shell am start -n com.ljrh.volumecontrol/.MainActivity
```

APK 名称从 Gradle 的版本号和构建类型生成，格式为 `轻控_v<versionName>_<variant>.apk`。当前 Debug 产物为 `app/build/outputs/apk/debug/轻控_v1.0_debug.apk`，Release 产物为 `app/build/outputs/apk/release/轻控_v1.0_release.apk`。

Release 自动签名已配置在 `app/build.gradle.kts`，签名材料位于本机 `signing` 目录：

- `20261022221516_轻控发布签名.p12`：PKCS12 密钥库，RSA 3072 位，有效期 10000 天。
- `20261022221516_签名信息.properties`：记录签名文件相对路径、密钥库密码、别名及密钥密码，Gradle 按 UTF-8 读取。

整个 `signing` 目录已加入 Git 忽略，签名文件和密码文件权限均为 `600`。请备份这两个文件，后续发布更新需沿用相同签名。缺少签名材料时 Debug 仍可构建，Release 会被签名校验拦截。

构建正式签名 APK：

```sh
env JAVA_HOME='/Applications/Android Studio.app/Contents/jbr/Contents/Home' ./gradlew assembleRelease
```

本轮已执行 `:app:assembleRelease :app:assembleDebug` 并构建成功，两种 APK 的实际文件名与输出元数据一致。`apksigner verify --verbose --print-certs` 验证 Release APK 通过，证书 SHA-256 与本机密钥库导出的证书一致：`a88ecf9027f42cdb7ff50efdfae2e97fbcc4d67e9d30503b49d51c8aa9d429a5`。Release APK 的版本为 `1.0`，未设置 `debuggable`。此次签名配置工作未向手机安装 Release 包。

真机回归测试命令：

```sh
env JAVA_HOME='/Applications/Android Studio.app/Contents/jbr/Contents/Home' ./gradlew connectedDebugAndroidTest
```

当前 Android Gradle Plugin 的测试运行器会在测试结束时卸载被测 APP 和测试包，执行后需要重新安装 APK、检查磁贴。此次交付已完成最终重新安装。

## 关键实现位置

- `ui/MainActivity.kt`：生命周期、前台音量同步、相机权限和添加磁贴。
- `data/MediaVolumeController.kt`：APP 和磁贴共同使用的媒体音量控制。
- `data/TorchController.kt`：闪光灯能力发现、系统回调和错误处理。
- `service/MediaVolumeTileService.kt`：唯一的媒体音量磁贴与快捷面板状态同步。
- `ui/VolumeSliderActivity.kt`：磁贴启动的悬浮滑条及实时系统媒体音量更新。
- `ui/VolumeControlScreen.kt`：主页面和磁贴帮助。
- `res/values/strings.xml`、`ui/theme/Theme.kt`：中文文案与配色。

源码按 MVVM 分为 `ui`（View 层，Activity 与 Compose 页面）、`data`（Model 层，媒体音量与闪光灯能力）、`service`（快捷设置磁贴）三个包；View 层内的主题单独放在 `ui/theme`。

源码和资源使用 Android/Kotlin 约定名称；生成图片、文档及验收记录采用时间戳与中文文件名。
