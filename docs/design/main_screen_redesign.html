VolumeControl · 主界面重设计

三个方向，选一个

现在的问题不是功能不够，而是五个板块平铺：标题、音量卡、手电筒卡、磁贴说明卡、页脚，眼睛没有落点。 新方案统一把音量做成唯一主角，手电筒压成右上角的常驻小控件，其余信息降级成一行。

去掉音量 ± 键 滑条每档触感反馈 手电筒右上角，开关在图标上方 磁贴入口收成一行 最终采用：方案 A + 方案 B 卡片

怎么选

对比项方案 A 极简大字方案 B 卡片聚焦方案 C 仪表刻度
视觉重量最轻，几乎只有数字和滑条中等，一张主卡压住全场偏重，刻度带来仪表感
信息密度最低，档位收进右上胶囊中等，三行细账最高，三块数据补充
上手成本最低低中，刻度需要一点阅读
小屏表现最好，滚动最少好一般，内容偏满

三个方案共用的改动：删除音量 ± 按钮；滑条成为唯一调节入口，拖动时按档位触发系统触感反馈（HapticFeedbackConstants.CLOCK_TICK）， 可在「震动 / 声音 / 关闭」之间切换；手电筒固定右上角，开关在图标正上方，与标题同一水平线，无闪光灯或相机被占用时图标变灰、开关禁用； 磁贴说明从整张卡降级为一行入口，点击才展开原来的详细步骤。
